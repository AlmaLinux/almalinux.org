{{ i18n "The AlmaLinux voice" }} #

{{ i18n "AlmaLinux is a community project run by volunteers. In copy, sound like a helpful person who is glad you are here: warm, plain, and confident, never hype. Write 'AlmaLinux' as one word with a capital A and L, and use a colon, a period, or parentheses instead of long dashes." }}

{{ i18n "Logos & assets" }} #

{{ i18n "Do" }}

  • {{ i18n "Use the white logo on dark backgrounds and the color logo on light backgrounds." }}
  • {{ i18n "Keep clear space around the logo of at least the height of the 'A' mark." }}
  • {{ i18n "Respect a minimum size so the wordmark stays legible." }}
  • {{ i18n "Write AlmaLinux as one word, with a capital A and L." }}

{{ i18n "Do not" }}

  • {{ i18n "Recolor, stretch, rotate, or add effects to the logo." }}
  • {{ i18n "Place the logo on a busy or low-contrast background." }}
  • {{ i18n "Write it as 'Alma Linux' or lowercase it to 'Almalinux'." }}
