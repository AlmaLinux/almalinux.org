{{ i18n "Built for the demands of research" }}

{{ i18n "What HPC teams need from a base OS: a long lifecycle, compatibility, fast fixes, and current tools." }}

{{ i18n "A lifecycle that matches research timelines" }}

{{ i18n "AlmaLinux 9 is supported through 2032, and AlmaLinux 10 through 2035. A cluster you build today can run for its whole hardware life without a forced OS migration partway through a grant." }}

{{ i18n "Compatible with RHEL and the HPC stack" }}

{{ i18n "Schedulers, parallel filesystems, vendor drivers, and ISV codes that list RHEL as supported run on AlmaLinux unchanged. OpenHPC's 3.x and 4.x releases target Enterprise Linux 9 and 10." }}

{{ i18n "Fast, open security patching" }}

{{ i18n "We build and ship security fixes quickly, and the work happens in public, so you can see and engage with the volunteers working on the problem. Research teams at CERN, UCL, and CSIC all named this as a reason they run AlmaLinux." }}

{{ i18n "Current compilers and GPUs" }}

{{ i18n "The system GCC stays steady so the ABI doesn't break, and current GCC ships alongside it in gcc-toolset packages, so you can compile with GCC 15 against a stable runtime. If you build your own toolchains, Spack publishes official AlmaLinux 8 and 9 images to build them on." }}

{{ i18n "For GPUs, we build and ship NVIDIA driver packages for AlmaLinux 9 and 10, and one package sets up NVIDIA's CUDA repository alongside them." }}

{{ i18n "Install NVIDIA drivers and CUDA" }}

{{ i18n "Benefits specifically for our community" }}

{{ i18n "AlmaLinux 10 adds a few things on top of RHEL compatibility: an x86_64_v2 build for older hardware that RHEL 10 drops, and Btrfs support, including booting from a Btrfs volume. It runs on x86_64, aarch64, ppc64le, and s390x." }}

{{ i18n "For the community, by the community" }}

{{ i18n "AlmaLinux is free for anyone to download and run, on one workstation or a thousand compute nodes, with no subscription manager or license tracking. It's just as free and easy to get involved: the project is governed by its members, roadmap discussions happen in public, and HPC users are welcome to help shape them." }}
